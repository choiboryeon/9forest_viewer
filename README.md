# 9FOREST Viewer

[Open the 9FOREST viewer](https://choiboryeon.github.io/9forest_viewer/9forest_viewer.html)

상단 **공간** 메뉴에서 **Night Shift / WESS+ / 공간 힘 · 지하**를 선택할 수 있습니다. Night Shift와 WESS+는 기존 20개 사물 라이브러리를 공유하고, 공간 힘은 공연 기자재만 표시합니다.

[WESS+ 바로 열기](https://choiboryeon.github.io/9forest_viewer/9forest_viewer.html?space=wess)

[공간 힘 바로 열기](https://choiboryeon.github.io/9forest_viewer/9forest_viewer.html?space=spacehim)

공간 힘에는 기본 공연 배치로 QSC K8 PA 스피커 2대와 각각의 삼각 스탠드, 믹서 1대, 0.3:1 단초점 프로젝터 1대를 놓았습니다. 기자재는 드래그하거나 X/Y 좌표·방향을 입력해 이동할 수 있습니다. 스피커는 스탠드와 바닥 거치를 전환하고 스탠드 높이를 조정합니다. 프로젝터는 바닥 가까이 두고 남쪽 긴 벽이나 서쪽 벽을 향하게 회전하면, 렌즈와 벽 사이 거리에서 16:9 투사 화면 크기와 벽면 적합 여부를 표시합니다. 이 공간에는 사물을 추가할 수 없습니다.

K8 본체는 [QSC 원본 K 시리즈 사양서](https://in.qscaudio.com/resource-files/productresources/spk/k/q_spk_k_specs.pdf)의 450 × 280 × 269 mm를 사용했습니다. 스탠드·믹서·프로젝터의 외형과 렌즈 오프셋은 실제 기종이 정해지지 않아 배치 검토용 근사치입니다. 투사 화면은 **투사비 0.3:1**로 계산하며 광량은 간이 미리보기입니다. 기종별 광학 특성, 정밀 조도, 음향, 전원 및 케이블 동선은 시뮬레이션하지 않습니다. 설치 전 현장 실측과 장비 사양 확인이 필요합니다.

K8은 사다리꼴 캐비닛, 전면 타공 그릴, 매립 손잡이, 후면 패널을 포함한 모델로 교체했습니다. [Blender·OBJ·GLB 원본](assets/equipment/qsc-k8/)이 있으며 장비 설정의 **장비 확대**로 형상을 볼 수 있습니다. [공간 힘 구조 검토 보고서](docs/spacehim-model-review.md)에 도면·사진과의 대조 결과를 기록했습니다. 도면의 미확인 부재 두 개는 기본 숨김이며 **도면 미확인 부재** 옵션으로 표시할 수 있습니다.

공간 힘의 **레일 조명** 메뉴에서 기존 천장 레일 4줄에 제안한 LED 스폿 12개를 조절합니다. 조명을 선택해 켜기·끄기, 전체·개별 밝기, 가정 광속, 색온도, 빔 각도와 방향·기울기를 바꿀 수 있습니다. 평면에서는 조명 기구를 드래그해 레일 위 위치를 옮깁니다. 조명은 최대 12개까지 추가·삭제할 수 있고, **전시 / 공연 / 암전** 프리셋을 제공합니다. **암실 조명 보기**에서는 기존 표시용 광원을 끄고 레일 조명과 프로젝터의 빛·그림자 및 간이 반사광을 표시합니다. 이 옵션을 끄면 배치 작업용 밝기가 더해집니다. 광량과 반사광은 배치 비교를 위한 근사치이며 실측 조도 예측용은 아닙니다. 조명 설정도 공간별 자동 저장 및 JSON 내보내기에 포함됩니다.

레일 조명의 기본 색온도는 차가운 백색광인 **6,500 K**, 기본 페더는 **60%**입니다. 조명을 선택하면 패널 상단에서 수평 회전(0–360°), 상하 기울기(0–90°), 빔 각도와 페더(0–100%)를 슬라이더나 숫자로 조절합니다. **전체 6,500 K**와 **이 페더 전체 적용**으로 여러 조명에 한꺼번에 적용할 수 있습니다. 빛 범위의 안쪽 점선은 페더가 시작되는 범위를 나타냅니다.

레일 조명의 **주변 반사광**은 기본으로 켜져 있습니다. 빛이 닿은 바닥·벽에서 반사된 빛과 천장·맞은편 면을 통한 추가 반사를 위치별로 계산해, 직접 빛이 닿지 않는 주변 벽·바닥·기자재에도 밝기와 색이 나타납니다. 조명을 이동·회전하거나 밝기·색온도를 바꾸면 함께 갱신됩니다. 벽·기둥·기자재의 가림을 반영하며 카메라의 벽 잘라보기와는 별개로 계산합니다. **반사광 강도**(0–200%)로 효과를 조절하고 배치 파일에도 저장합니다.

프로젝터를 선택하면 **프로젝터 화면과 반사광**에서 켜기·끄기, 화면 밝기와 가정 광속(기본 3,000 lm)을 바꿀 수 있습니다. 흰색·검정·단색 화면, 밝기 변화 테스트 또는 직접 불러온 이미지·영상을 투사합니다. 화면이 밝아지면 인접 벽·바닥의 반사광도 밝아지고, 화면 색을 반영합니다. 영상은 프레임 내용을 분석해 반사광을 계속 갱신하며 소리 없이 반복 재생됩니다. 레일 조명의 **암전**으로 프로젝터 빛만 확인할 수 있고, 프로젝터는 따로 끌 수 있습니다. 벽면에 들어가는 유효한 배치에 적용합니다. 미디어는 브라우저 안에서 읽고 서버로 업로드하지 않습니다. 배치에는 화면 설정과 축소한 대표 이미지를 저장합니다. 영상은 다시 열 때 파일을 선택해야 재생됩니다.

- 사물 추가, 드래그 이동, X/Y/Z 회전, 바닥·좌대·봉·천장 행잉을 지원합니다.
- 모든 공간에서 회전·이동의 관성을 제거했습니다. 마우스 드래그를 놓으면 카메라도 즉시 멈춥니다.
- 공간마다 배치를 별도로 자동 저장합니다. 공간을 바꾸어도 이전 배치를 유지합니다.
- JSON 저장 파일에는 `space_id`가 포함됩니다. 불러오면 해당 공간으로 자동 전환합니다. 공간 정보가 없는 기존 version 2/3 파일은 Night Shift 배치로 읽습니다.
- 입체·평면·네 방향 시점, 천장/구조물/설비/벽 표시, PNG 저장, 다크 모드를 지원합니다.
- WESS 배치는 벽·기둥·창·열린 문과 바닥 외부를 피하도록 보정합니다. 사물끼리 겹치면 기존 경고를 표시합니다. 워킹은 벽과 사물을 피하고 접근할 수 없는 사물은 제외합니다.

WESS는 도면에서 만든 `WESS_Plus_Space.obj`를 원래 미터 단위와 Z-up 좌표 그대로 반영했습니다. 주실 내측 치수는 7.920 × 4.565 m, 중앙실 단차는 +30 mm입니다. 벽 높이 2.70 m와 선택 표시하는 평천장은 가정값입니다. 처음 WESS를 선택하면 빈 공간이 열려 원하는 사물을 추가할 수 있습니다. 기존 설치안의 9개 작품은 이 20개 사물 라이브러리와 별개입니다.

배치 높이는 해당 위치의 바닥 위 높이입니다. WESS 로비 일부의 Y 좌표는 음수입니다. 계단은 공간 형상으로 표시하지만 사물 배치와 워킹 경로에서 제외합니다. 이 뷰어는 배치 계획 도구이며 실제 설치 시 실측과 구조 검토가 필요합니다.

## 개발 및 검증

Node.js 20 이상:

```sh
npm ci
npm run build
npm test
npm run serve
```

로컬 주소는 `http://127.0.0.1:4186/9forest_viewer.html`입니다. `src/`는 편집 가능한 원본, `data/`는 세 공간과 사물·기자재 데이터입니다. `tools/build.mjs`가 Three.js, 공간 모델, 사진을 하나의 `9forest_viewer.html`에 포함하므로 배포 후 CDN이나 모델 서버가 필요 없습니다. 기존 `index.html` 진입 경로와 단일 HTML 다운로드 방식도 유지됩니다.

WESS 원본 수정 시 `node tools/convert-wess.mjs`를 실행한 뒤 다시 빌드하세요. 변환은 5,588개 원본 삼각형의 좌표와 면 방향을 보존하는지 검사합니다. `data/wess-source/README.md`와 `data/wess-geometry-audit.json`에 출처, 치수와 가정을 기록했습니다.

공간 힘 원본은 `data/spacehim-source/`에 보관했습니다. `node tools/convert-spacehim.mjs`로 OBJ를 다시 변환할 수 있습니다. X·Y를 함께 회전해 원래 Blender 좌표 `(u,-v,Z)`로 복원한 167개 부재를 공간 모델로 저장합니다. 원본 삼각형이 모두 보존되는지 검사한 결과는 `data/spacehim-geometry-audit.json`에 남깁니다. `node tools/review-spacehim.mjs`는 검토 평면 SVG를 만듭니다. 바닥 배치 영역은 원본 `model_notes.json`과 도면을 바탕으로 보수적으로 구획했습니다. 공간 힘의 현재 JSON 형식은 레일 조명과 프로젝터 화면을 포함한 version 7입니다. 이전 version 4 배치의 좌표는 자동 이전되며, version 4/5 파일에는 기본 레일 조명을 추가합니다. 프로젝터 화면 설정이 없는 기존 파일은 흰 화면으로 시작합니다.

레일 조명 설정의 내부 형식은 version 3입니다. 이전 version 1 설정은 위치·각도·광량을 유지하면서 색온도를 6,500 K, 페더를 60%로 한 번 이전합니다. version 1/2 파일에는 주변 반사광과 기본 강도 100%를 추가합니다. 이미 조절한 version 2의 색온도·각도·페더는 유지됩니다. 이후 사용자가 바꾼 값도 재접속하거나 파일을 불러와도 유지됩니다.

레일 반사광은 실제 공간의 삼각형을 BVH로 검사해 조사면과 반사 경로의 가림을 구합니다. 조명마다 여러 조사 지점을 샘플링하고 한 단계의 추가 반사를 근사합니다. 결과는 약 0.6 m 간격의 방향성 조도 격자에 저장해 공간과 기자재 재질에서 읽으며, 기존의 균일한 표시용 반사광은 암실 모드에서 제거했습니다. 위치·방향을 바꿀 때만 해당 조명을 다시 계산하고 밝기·색온도 조절은 계산 결과를 재사용합니다. 반사율·격자·다중 반사는 설치 비교용 근사값이며 실측 조도 예측은 아닙니다.

프로젝터 반사광은 화면의 선형 RGB 평균과 가정 광속·반사율에서 구한 광원 두 개로 근사하며 그림자를 적용합니다. 한 투사면은 좌우 두 구역을 샘플링하고, 여러 투사면에서는 가장 밝은 두 면에 각각 광원 하나를 배정해 그림자 계산량을 제한합니다. 영상·테스트 패턴은 약 12 fps로 갱신합니다. 실제 프로젝터의 블랙 레벨, 벽면 반사 특성과 광학 손실을 측정한 조도 계산은 아닙니다.

Chrome이 설치된 환경에서 로컬 서버를 켠 뒤 `npm run test:browser`로 드래그, 공간별 저장, JSON/PNG, 워킹 전환, 모바일, 관성 없는 카메라 이동, 레일 조명과 프로젝터의 화면·반사광을 검사할 수 있습니다. 다른 Chrome 실행 파일은 `CHROME_PATH`, 다른 서버 주소는 `VIEWER_URL` 환경 변수로 지정합니다. 스크린샷과 결과는 Git에서 제외된 `test-results/browser/`에 저장됩니다.
